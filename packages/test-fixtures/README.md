# Test fixtures

Everything here is **synthetic and written from scratch** for this project (see docs/provenance.md).
It contains no SAP-owned files and nothing derived from third-party IDE plugins.

- `hybris/` – a tiny fake commerce workspace in the real layout (`config/`, `bin/platform/ext`, `bin/custom`) with
  stand-ins for the base types (core, catalog) and three custom extensions. Used by the platform-model, type-system
  and language tests.
