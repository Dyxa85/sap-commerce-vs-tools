# The Features view

Open the **Features** view in the SAP Commerce side bar. Every feature of the extension is listed there, grouped by what
you want to do, with the place where it also lives (shortcut, menu or file type). Click an entry to run it.

Everything is also available in the Command Palette: type `SAP Commerce`.

AI assistants: a bundled MCP server gives read-only project knowledge to Copilot's agent mode. See _MCP: List Servers_
in the Command Palette and the setting `sapcommerce.mcp.enableQueries` (off by default).
