# Your project in the side bar

Click the **SAP Commerce** icon in the activity bar (the hexagon with `< >`).

**Commerce Project** lists the platform, the modules and your custom extensions in load order. Open an extension to see
its real folders – `src`, `gensrc`, `resources`, `testsrc` – and files like `build.xml` and `extensioninfo.xml`. The node
**Commerce overview** inside each extension groups the type system, beans, Spring, business processes, ImpEx files and
the dependencies.

Nothing is shown? Open the folder that contains the `hybris` directory, or set `sapcommerce.project.roots` in the
settings.

For a CCv2 repository (`core-customize/manifest.json`) the **CCv2** view shows the repository and an outline of the
manifest.
