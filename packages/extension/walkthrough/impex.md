# ImpEx

Files ending in `.impex` get highlighting, completion for types, attributes and enum values, diagnostics that follow what
the importer really does (unknown types, missing unique columns, macros …), a formatter and quick fixes.

- `Cmd+Alt+V` / `Ctrl+Alt+V` validates the file on the active connection.
- **Import ImpEx…** imports it after you confirm.
- Hover a type or attribute to see where it is defined; `Cmd/Ctrl+click` jumps to the `items.xml`.
