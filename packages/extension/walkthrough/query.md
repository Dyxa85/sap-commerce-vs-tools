# Run a query

1. Create a FlexibleSearch file (the button creates one) or save any file as `.flexibleSearch`.
2. Type a query, for example `SELECT {pk}, {isocode} FROM {Language}`.
3. Press `Cmd+Enter` / `Ctrl+Enter`, or use the button in the editor title bar.

Select part of the text to run only that part. `?parameters` are asked for. The result table can be sorted, filtered and
exported as CSV or JSON. SQL (`.sql` files) and Groovy (`.groovy` files) work the same way from the editor context menu.
