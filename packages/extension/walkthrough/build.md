# Build, run, debug

- **Run Ant Target…** – `build`, `clean`, `unittests`, or your own target with `-D` properties. The same targets are tasks
  (Terminal → Run Task). Compiler errors appear in the Problems panel.
- **Start Server** / **Start Server in Debug Mode** / **Stop Server**, then **Attach Debugger to Server**.
- **Configure Java for this Project…** writes the settings for the _Language Support for Java™ by Red Hat_ extension from
  the extensions your platform loads.
