## SAP Commerce VS-Tools 0.1.5 – CCv2 back in the project tree, icons for the main entries

### What changed

- **The CCv2 repository is at the top of the Commerce Project view**, as in the IDE: `core-customize` with its files, an
  outline of `manifest.json`, and `hybris` with `config` and `bin/custom`. The separate **CCv2** view stays.
- **Icons for the main entries**: the project (hexagon), Configuration, Custom, Modules, Platform and the CCv2 repository.
  They are our own drawings and work in light and dark themes.

### Fixed

- **The CCv2 view was empty when the opened folder is inside `core-customize`**, for example the `hybris` folder. The
  repository is now also found from the folders above the opened one and from the `hybris` folder of every project found.

### Install or update

1. Download `sap-commerce-vs-tools-0.1.5.vsix` below (`SHA256SUMS.txt` lets you verify it).
2. VS Code → Extensions → `⋯` → **Install from VSIX…** and reload the window. Connections and passwords are kept.
