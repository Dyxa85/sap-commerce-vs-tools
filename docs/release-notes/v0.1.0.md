## SAP Commerce VS-Tools 0.1.0 – first release candidate

Developer tools for **SAP Commerce** (`2211-jdk21`) in **VS Code 1.101+**. Unofficial: not affiliated with SAP SE.

### Install

1. Download `sap-commerce-vs-tools-0.1.0.vsix` below.
2. VS Code → Extensions → `⋯` → **Install from VSIX…** (or `code --install-extension sap-commerce-vs-tools-0.1.0.vsix`).
3. Open the folder with your `hybris` directory and run **SAP Commerce: Add Connection…**

Full guide: [How to enable it in VS Code](https://github.com/Dyxa85/sap-commerce-vs-tools/blob/main/docs/howto-enable-in-vscode.md) ·
[auf Deutsch](https://github.com/Dyxa85/sap-commerce-vs-tools/blob/main/docs/howto-enable-in-vscode.de.md).
`SHA256SUMS.txt` lets you verify the download.

### Highlights

- **hAC from the editor**: FlexibleSearch, SQL, Groovy (rollback by default), ImpEx validate/import, PK analyzer, log levels, history; several connections with protected environments.
- **ImpEx and FlexibleSearch language support** whose diagnostics follow what the importer and the hAC really do (measured on a real instance): types, attributes, macros, unique columns, hAC pitfalls; completion, hover, formatter, quick fixes.
- **Project knowledge** from `items.xml`, `beans.xml`, Spring and business-process files: go to definition across extensions and Java sources, completion, override awareness. The type system matches a running 2211 instance (999 of 1,004 compared types identical, the rest explained by extensions missing in the checkout).
- **Commerce Project view**, type/bean preview, and **diagrams** for types, extension dependencies and business processes.
- **Build and run**: Ant targets as commands and tasks with a `javac` problem matcher, server start/stop/debug, debugger attach, Java settings for the Red Hat Java extension.
- **MCP server** for AI tools: read-only project knowledge; optional read-only queries (off by default, confirmed on every start).

### Security and privacy

Passwords in VS Code's secret storage bound to URL + user; TLS verification on by default; `http://` to remote hosts needs confirmation; writes ask first; strict webview CSP; workspace connections ignored in untrusted workspaces; **no telemetry**. See the [security review](https://github.com/Dyxa85/sap-commerce-vs-tools/blob/main/docs/security-review.md).

### Known limits – please read

- Developed and tested on **macOS**; CI also passes on Ubuntu and Windows (unit tests and tests inside VS Code).
- **Not yet verified:** the Java setup against a running Red Hat Java language server, the MCP server from Copilot's agent mode, a real `ant build` started from the task.
- **Not implemented:** ACL and Polyglot Query editors (no public specification), debugger value renderers (no VS Code API). Planned: CCv2, Solr, Cockpit NG – see the [roadmap](https://github.com/Dyxa85/sap-commerce-vs-tools/blob/main/ROADMAP.md).
- Per-feature evidence: [docs/parity.md](https://github.com/Dyxa85/sap-commerce-vs-tools/blob/main/docs/parity.md).
