# ImpEx behaviour observed on a real instance (2211-jdk21)

Derived by running probe scripts against the maintainer's own local instance (validation endpoint, import of no-op
`UPDATE` statements on non-existing items, and one throw-away `Title` item that was removed again).
This is the ground truth for the parser and diagnostics. No third-party source code was consulted.

| Topic                                   | Observation                                                                                                                                                                                               |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Validation (`IMPORT_STRICT`)            | Weak: reports only unbalanced `"`, unbalanced `[`/`(`, unknown attributes/types in headers, ambiguous (duplicate) columns. It does **not** report unknown modes, cell-count mismatch or undefined macros. |
| Modes                                   | Case-insensitive (`insert_update` works).                                                                                                                                                                 |
| Unknown mode (`UPDATEX Type;…`)         | Line is not a header: import fails with "no current header for value line".                                                                                                                               |
| Header without type (`UPDATE ;a`)       | Not a header → "no current header for value line" for the rows.                                                                                                                                           |
| Value row before any header             | "no current header for value line".                                                                                                                                                                       |
| More cells than header columns          | Extra cells are ignored silently.                                                                                                                                                                         |
| Fewer cells than header columns         | Allowed; missing cells are empty.                                                                                                                                                                         |
| `# text` after a value                  | **Not** a comment; it becomes part of the value. Comments only start a line.                                                                                                                              |
| Undefined macro `$x`                    | No error; the text `$x` is used literally.                                                                                                                                                                |
| Macros                                  | `$a=v`, `$a = v` (spaces around `=`), macros may reference earlier macros.                                                                                                                                |
| Header spanning lines                   | Not supported. An indented follow-up line is parsed as a **value row** (and fails confusingly).                                                                                                           |
| First cell of a value row               | May be non-empty (type column, e.g. sub-type).                                                                                                                                                            |
| Quotes                                  | `"…"` may contain `;` and newlines; `""` is an escaped quote; an odd number of `"` in the file is an error ("File is corrupt").                                                                           |
| Whitespace                              | Leading/trailing whitespace of cell values is trimmed, also for quoted values. Column alignment with spaces is safe.                                                                                      |
| `#%` lines                              | Accepted; execution needs `enableCodeExecution`.                                                                                                                                                          |
| Unknown modifier (`[nosuchmod=1]`)      | Not reported by validation.                                                                                                                                                                               |
| Macro substitution                      | **Textual**: with `$p=zz`, `$pNone` becomes `zzNone` and `a$p` becomes `azz`. When several defined names match, the **longest** wins. A macro defined _after_ its use is not substituted.                 |
| `INSERT_UPDATE` without a unique column | Rejected in strict mode ("at least one attribute has to be declared as unique"), same as `UPDATE`/`REMOVE`.                                                                                               |
| Duplicate columns                       | `isocode[unique=true];isocode` is rejected ("ambiguous columns"); the same attribute with different `lang` values is fine.                                                                                |
| `mode` modifier                         | Values `append`, `remove`, `replace`.                                                                                                                                                                     |
| Type modifiers seen in real projects    | `processor`, `batchmode`, `disable.interceptor.beans`, `disable.interceptor.types`.                                                                                                                       |
