## How the numbers were produced

```bash
pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build   # 426 unit tests
pnpm --filter sap-commerce-vs-tools run test:host                              # 57 tests in VS Code 1.141
```

Other measurements (real platform, 234 extensions, 1,488 item types, 1,513 beans): full index in 1.25 s, language-server
process 164 MB RSS (of which Node itself ≈ 41 MB; budget 200 MB); extension activation is asserted < 500 ms in a host test;
the fuzz test (250 mutations per sample in the normal run, 5,000 tried once) found no exception in any parser, analyzer,
formatter or editor feature; the 234-extension graph lays out in 10 ms.

The host tests were also run against the minified production bundle (57 passing) and the packaged VSIX installed cleanly
into a throw-away profile. CI additionally runs the matrix on Linux, macOS and Windows; **only macOS was available
locally**, so the other two are unverified until the first CI run.
