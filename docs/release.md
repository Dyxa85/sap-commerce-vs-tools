# Releasing

## One-time setup (only the maintainer can do these)

1. The repository is `https://github.com/Dyxa85/sap-commerce-vs-tools`; `publisher` in `packages/extension/package.json`
   is `dyxa85`. **Change it if your Marketplace publisher id differs** (the id of a publisher cannot be renamed later).
2. In the repository settings enable **Private vulnerability reporting** (Security → Advisories); `SECURITY.md` and
   `CODE_OF_CONDUCT.md` point there.
3. _Only for store publication:_ create a publisher for the [Visual Studio Marketplace](https://marketplace.visualstudio.com/manage)
   and a namespace on [Open VSX](https://open-vsx.org); create access tokens and store them as repository secrets `VSCE_PAT`
   and `OVSX_PAT`. Without a secret, the workflow skips that store and only creates the GitHub release with the VSIX.
4. Upload `docs/images/social-preview.png` as the repository's **Social preview** (Settings → General) – GitHub offers no
   way to do that from a commit. It is what link previews show.
5. Add screenshots of the results table, ImpEx diagnostics and a diagram to the README (the diagram images in
   `docs/images/` are generated by `pnpm --filter @sapcommerce-vstools/dev-tools run demo:images`).

## Cutting a release

1. Write `docs/release-notes/vX.Y.Z.md` (the workflow uses it as the release text; versions below 1.0 are marked as pre-release).
2. Update `packages/extension/CHANGELOG.md` (move _Unreleased_ under the new version) and bump the version in
   `packages/extension/package.json`.
3. `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm --filter sap-commerce-vs-tools run test:host`
4. `git tag vX.Y.Z && git push --tags`. The _Release_ workflow re-runs all checks, verifies that the tag matches the
   version, builds the minified bundles, packages the VSIX, attaches it to a GitHub release and publishes to the stores
   whose token is set.

Local dry run of the package step:

```bash
pnpm --filter sap-commerce-vs-tools run package -- --allow-missing-repository
```
